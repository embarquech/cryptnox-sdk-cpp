Detailed Description

TRON address derivation and Base58Check encoding.

Stateless helpers. The Base58Check checksum is a double SHA-256, so the encode / decode entry points take the host's CW_CryptoProvider rather than bundling a second hash implementation. Keccak-256 is implemented internally — no adapter method is needed for it.

static

Decode and validate a Base58Check TRON address.

Rejects anything that is not a well-formed mainnet address: wrong length, characters outside the Base58 alphabet, a prefix other than 0x41, or a checksum mismatch. Use this on every address that arrives from outside the firmware (config, QR code, RPC response) before it is used to build or verify a transaction.

Parameters
[in]address34-character NUL-terminated Base58Check address.
[in]cryptoCrypto provider (used for the SHA-256 checksum).
[out]out21-byte output buffer for the raw address.
Returns
true if the address is valid and out was written, false otherwise (out is then left untouched).

Base58Check-encode a raw 21-byte TRON address.

Appends the first 4 bytes of sha256(sha256(addressBytes)) as the checksum and Base58-encodes the 25-byte result.
