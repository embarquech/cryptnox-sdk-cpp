Detailed Description

Implementation of TRON address derivation and Base58Check coding.

Contains a compact Keccak-f[1600] permutation (file-local) because TRON addresses are Ethereum-style keccak256 digests and no CW_CryptoProvider method provides Keccak. Base58 is done with plain long division / multiplication over the fixed 25-byte payload — no bignum library.

Self-check (no crypto provider needed, Keccak and Base58 only):

g++ -DCW_TRON_SELFTEST CW_Tron.cpp CW_Utils.cpp -o cw_tron_selftest
./cw_tron_selftest
