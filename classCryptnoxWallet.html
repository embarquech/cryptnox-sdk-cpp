Detailed Description

High-level interface for interacting with a Cryptnox smart card over NFC.

Manages card connection, secure channel establishment (delegated to CW_SecureChannel), PIN verification, signing, and user data writing.

Dependencies are injected by the caller. CryptnoxWallet interfaces exclusively with CW_SecureChannel (Secure Stack) and CW_Logger (Logging), keeping this class platform-independent.
